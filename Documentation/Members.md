## Team Work

The project will be developed as a group.

The team members will participate in different activities, such as:

- Requirements analysis.
- System design.
- Database design.
- Software development.
- Testing.
- Documentation.
- Presentation.

Git will be used to keep track of the changes made to the project, and GitHub will be used to share and manage the repository.


## Repository

All members of the group will be linked to the project repository.

The repository will contain the project documentation and, as the project progresses, the source code and other files related to Bella Dona ERP.
