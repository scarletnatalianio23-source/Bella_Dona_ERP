# Selected Technologies

## Introduction

For the development of Bella Dona ERP, we selected different technologies and tools that will help us create the web application, manage the database, and organize the project.

The technologies were selected according to the type of system we want to develop and the tools available to the team.



## Microsoft Web

Microsoft Web technologies will be used as the main environment for the development of the web application.

They will allow us to create the different parts of the system and connect the application with the database.


## C#

C# will be the main programming language used in the project.

We will use C# to develop the logic of the application and manage the different processes of Bella Dona ERP.

For example, C# can be used for:

- Managing products.
- Registering sales.
- Managing customers.
- Managing suppliers.
- Controlling inventory.



## ASP.NET

ASP.NET will be used to develop the web application and its backend.

It will allow us to create the different functionalities needed for Bella Dona ERP.

ASP.NET will also allow the application to communicate with the SQL Server database.



## SQL Server

SQL Server will be used as the database management system.

The database will store the information needed by the ERP, such as:

- Products.
- Inventory.
- Sales.
- Customers.
- Suppliers.
- Users.
- Purchases.

This will allow the information to be stored in an organized way.



## Visual Studio Code

Visual Studio Code will be used as the main development environment.

We will use it to:

- Write the code.
- Organize project files.
- Edit the application.
- Work with the selected technologies.
- Manage the project during development.



# Technology Summary

| Area | Technology |
|---|---|
| Web Development | Microsoft Web |
| Programming Language | C# |
| Web Framework | ASP.NET |
| Database | SQL Server |
| Development Environment | Visual Studio Code |



# Why We Selected These Technologies

We selected these technologies because they are suitable for developing the type of web application we are planning.

C# and ASP.NET will be used to develop the application and its main functions.

SQL Server will be used to store and manage the information generated by the ERP.

Visual Studio Code will be our main development environment.

These technologies will also allow us to apply programming, database, and software development concepts that we have learned during the degree.
