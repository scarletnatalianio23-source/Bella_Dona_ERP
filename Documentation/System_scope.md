# System Scope

## Introduction

The scope defines what we plan to include in the first version of Bella Dona ERP.

Since this is an academic project, we need to consider the available time, resources, and the main needs of the business.



# Included in the Project

The first version of Bella Dona ERP will focus on five main areas.



## 1. Inventory

The system will include:

- Product registration.
- Product editing.
- Product classification.
- Stock entries.
- Stock exits.
- Stock consultation.
- Low-stock alerts.



## 2. Sales and Billing

The system will include:

- Sales registration.
- Product availability consultation.
- Order tracking.
- Digital receipts.
- Sales information.



## 3. Customer Management

The system will include:

- Customer registration.
- Customer information.
- Customer order history.
- Customer style preferences.



## 4. Suppliers and Purchasing

The system will include:

- Supplier registration.
- Supplier information.
- Purchase registration.
- Purchase order control.



## 5. Reports

The system will include basic reports about:

- Sales.
- Revenue.
- Inventory.
- Best-selling products.



# Not Included in the First Phase

The first version will not include a real-time payment gateway.

Other advanced functions may also be left for future versions if they are outside the available time and resources.



# Triple Constraint

The project will consider three main restrictions:

- Scope.
- Time.
- Cost.



## Scope

The main scope is the development of:

- Inventory.
- Sales.
- Customer Management (CRM).
- Suppliers and Purchasing.
- Reports.

The first phase will not include a real-time payment gateway.



## Time

The project will be developed during the academic semester.

Because the development time is limited, we will focus first on the most important functions of the ERP.



## Cost

The planned budget for the project is:

**$0 COP**

We plan to use the available technologies and tools without adding unnecessary costs.



# Project Limitations

The main limitations are:

- Limited development time.
- Academic project requirements.
- Limited budget.
- Some advanced ERP functions will not be included in the first version.
- The final system may change according to the requirements identified during development.



# Expected Result

At the end of the project, we expect to have a web-based ERP that helps Bella Dona organize its main business information and reduce the amount of manual work currently done using Excel.
