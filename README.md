# BELLA DONA ERP

## About the Project

Bella Dona ERP is a project developed for a small business called Bella Dona, which sells gothic necklaces and accessories for women.

Currently, most of the business information is managed manually using Excel. This makes it difficult to keep track of products, inventory, sales, customers, and suppliers.

Our idea is to develop a web-based ERP system that allows the business to have its main information in one place.



## Problem

Bella Dona currently has some difficulties with the way information is managed.

The main problems are:

- Product information is managed manually.
- Inventory is controlled using Excel and visual checking.
- Daily sales are recorded manually.
- There is no organized customer database.
- Supplier information is not centralized.
- It takes time to keep all the information updated.
- Manual processes can cause errors or missing information.



## Proposed Solution

Our proposal is to develop **Bella Dona ERP**, a web application that will help organize the main processes of the business.

The system will focus on:

- Product management.
- Inventory management.
- Sales and billing.
- Customer management.
- Supplier and purchasing management.
- Reports.

The main idea is to have the business information in one system instead of managing it through different manual records.



## General Objective

Develop a web-based ERP system that helps Bella Dona organize and manage its main commercial processes.



## Specific Objectives

- Organize product information.
- Improve inventory control.
- Register sales in a more organized way.
- Manage customer information.
- Organize supplier information.
- Generate basic business reports.
- Reduce manual work.
- Make business information easier to consult.



## Main Users

| User | Main Functions |
|---|---|
| Administrator | Manage products, inventory, sales, customers, suppliers, and reports. |
| Salesperson | Register sales and check product availability. |
| Inventory Manager | Register product entries and exits and check stock. |
| Customer | View product information and make purchase requests if this option is included. |

## Selected Technologies

The main technologies selected for the project are:

- Microsoft Web.
- C#.
- ASP.NET.
- SQL Server.
- Visual Studio Code.

These technologies will be used to develop the web application, create the system logic, manage the database, and organize the project code.


## Project Scope

The first version of Bella Dona ERP will focus on five main areas:

- Inventory.
- Sales.
- Customer Management (CRM).
- Suppliers and Purchasing.
- Reports and Analytics.

A real-time payment gateway will not be included in the first phase.
